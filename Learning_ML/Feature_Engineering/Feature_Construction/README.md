# 🧩 Feature Construction

Welcome to the **Feature_Construction** section of my **Feature Engineering** journey!

This folder contains my notes and implementations for creating **new, meaningful features from existing variables**. Feature construction helps transform raw data into more informative representations that can make patterns easier for machine learning models to learn.

---

## 📘 Notebooks Included

### 🔹 Feature_Construction_Splitting.ipynb

In this notebook, I explored **feature construction and feature splitting** using the **Titanic dataset**.

#### Topics Covered

* Understanding the concept of feature construction
* Creating new features by combining existing variables
* Creating `Family_size` using `SibSp` and `Parch`
* Converting `Family_size` into meaningful categories using `Family_type`
* Extracting useful information such as `Title` from the `Name` variable
* Analysing the relationship between constructed features and the target variable
* Creating an `IsMarried` feature based on extracted information
* Comparing model performance before and after feature construction using Logistic Regression and cross-validation
