# Support Vector Machine (SVM)

## 1. Support_Vector_Machine.ipynb

- Introduction to Support Vector Machine (SVM) classification.
- Implementing SVM using the Iris dataset.
- Visualizing different flower classes using Sepal Length, Sepal Width, Petal Length and Petal Width.
- Understanding and experimenting with the Regularization parameter (`C`).
- Understanding the `gamma` parameter.
- Exploring different SVM kernels.
- Implementing a Linear Kernel using `SVC(kernel='linear')`.

## 2. Support_Vector_Machine_Kernel_Trick.ipynb

- Understanding the Kernel Trick in Support Vector Machines.
- Implementing SVM classification using the `make_circles` dataset.
- Exploring Linear Kernel SVC and visualizing its decision boundary.
- Understanding the limitations of linear kernels for non-linearly separable data.
- Exploring the Radial Basis Function (RBF) Kernel.
- Understanding the RBF transformation using a 3D visualization.
- Implementing RBF Kernel using `SVC(kernel='rbf')`.
- Exploring Polynomial Kernel using `SVC(kernel='poly')`.
- Experimenting with different polynomial degrees using the `degree` parameter.
- Comparing the classification performance of Linear, RBF and Polynomial kernels.
- Visualizing and comparing decision boundaries for different kernels.
