# 🌿 Decarbonizing Corporate Travel & Scope 3 Logistics Mining
> **An Empirical Machine Learning Pipeline & Process Mining Framework to Intercept and Mitigate High-Carbon Corporate Logistics**

---

## 📌 Project Overview

Corporate logistics and business travel represent major Scope 3 GHG emissions drivers for modern enterprises. This repository hosts an end-to-end Machine Learning and Process Mining pipeline designed to analyze, predict, and intercept high-carbon corporate travel choices *prior to booking confirmation*.

By combining predictive modeling with event-log process mining, this project addresses structural inefficiencies, late-approval bottlenecks, and non-compliant booking behaviors across **65,289 historical trip records** and **671,547 reconstructed event log steps**.

### **Key Metrics & Insights**
* **Training Dataset Size:** 65,289 trips (`public_trip_data.csv`)
* **Private Evaluation Dataset Size:** 21,764 trips (`private_trip_data.csv`)
* **Event Log Volume:** 671,547 event steps (`public_trip_event_log.csv`)
* **Target Variable (`HighCarbon`):** Binary classification (74.99% Normal / Class 0 vs. 25.01% High-Carbon / Class 1 — exact **3:1 class imbalance ratio**)
* **Primary Bottleneck Identified:** **6.4 days average approval latency**, forcing last-minute flight bookings on short-haul corridors.
* **Top Operational Hotspots:** **Customer Visits** (28,229 journeys), **Partner Relations** (15,412 journeys), and **Internal Meetings** (9,114 journeys).

## 💻 Detailed Notebook Walkthrough

1. Data Loading & Initial Exploration (EDA)
Dataset Ingestion: Loaded four core files (public_trip_data.csv, private_trip_data.csv, public_trip_event_log.csv, and public_trip_event_attributes.csv).
Structural Audits: Inspected dataset dimensions (shape), column data types (info()), summary statistics (describe()), duplicate records (duplicated()), and missing value distributions (isnull().sum()).
Target Class Analysis: Analyzed the distribution of the binary target HighCarbon (48,963 Normal / 74.99% vs 16,326 High Carbon / 25.01%), establishing a clear 3:1 class imbalance ratio requiring weighted cross-entropy / inverse frequency parameter tuning ($w_0 = 0.67$, $w_1 = 2.00$).

2. Target Leakage Identification & Sanitization
Identified and isolated features that directly expose CO₂ calculations prior to training:$$\text{Leakage Columns} = \{\text{Departure\_CO2e}, \text{Return\_CO2e}, \text{Hotel\_CO2e}, \text{Spend\_CO2e}, \text{TotalCO2e}\}$$
Dropped all leakage variables along with non-predictive database identifiers (TripID, EmployeeNumber) to prevent shortcut learning and over-fitting.

3. Numerical & Categorical Feature Analytics
Numerical Feature Distributions: Visualized distributions via sns.histplot (KDE overlays) and identified significant right-skewness. Evaluated potential outliers using Interquartile Range (IQR) lower/upper bounds and sns.boxplot.
Correlation Heatmaps: Computed Pearson correlation matrices against HighCarbon to assess numerical predictive strength.
Categorical Feature Profiling: Plotted count distributions for ShippingTypeDescription, BusinessUnit, Purpose, OutOfPolicy, DepartureLocationCountry, ArrivalLocationCountry, and DepartureLocationCity.
Cross-Tabulation: Created normalized cross-tabulations (pd.crosstab) to evaluate high-carbon percentages per category.
Chi-Square Statistical Tests: Ran Chi-Square Tests of Independence (scipy.stats.chi2_contingency) to confirm statistically significant relationships between categorical variables and carbon intensity.

4. Process Mining & Event Log Analysis
Timestamp Normalization: Parsed EventTimestamp to Pandas datetime format.
Aggregation: Grouped 671,547 event steps by TripID to extract lifecycle attributes:NumberOfEvents: Total lifecycle action count per trip.ProcessDurationHours: End-to-end processing time ($\text{Timestamp}_{\max} - \text{Timestamp}_{\min}$) in hours.
Process Variant Tracking: Reconstructed event sequences ordered by StepOrder (Event1 → Event2 → ...) and evaluated process attributes (ProcessCode, DaysPreapproved, ExpenseReimbursementAmount, ReasonForDelay, ReasonForTransportationChange, ReasonForTransportCancellation).
Approval Bottleneck Discovery: Uncovered a major process bottleneck where request-to-approval delays averaged 6.4 days, depleting low-cost/low-carbon rail availability and forcing last-minute flight bookings.

5. Domain-Specific Feature Engineering & Preprocessing Pipeline
Engineered Core Features:IsInternational: Binary indicator flagging whether DepartureLocationCountry $\neq$ ArrivalLocationCountry.HasHotelStay: Binary flag derived from HotelNights > 0.CostPerNight: Vectorized ratio calculated as $\frac{\text{NetCosts}}{\text{HotelNights}}$ (handled division-by-zero safely).IsFlight: High-emission indicator flagging aviation modes (Business Class Flight, First Class Flight, Economy Flight).
Missing Value Imputation: Imputed numerical NaNs with dataset Medians and categorical NaNs with "Unknown".
Rare Category Bucketization: Grouped infrequent categorical values ($< 1\%$ dynamic frequency threshold) into an 'Other' bucket to prevent high cardinality.
Encoding & Scaling: Applied OneHotEncoder(handle_unknown='ignore', sparse_output=False) for categorical features and StandardScaler on numerical features for linear model benchmarking.

6. Model Benchmarking & Multi-Model Evaluation
Divided training data using an 80/20 Stratified Train-Test Split ($N_{\text{train}} = 52,231$, $N_{\text{test}} = 13,058$) with random_state=42. Evaluated multiple algorithms across Accuracy, Precision, Recall, F1-Score, and ROC-AUC:Logistic RegressionDecision Tree ClassifierRandom Forest ClassifierExtra Trees ClassifierGradient Boosting ClassifierXGBoost Classifier (Selected as the top-performing architecture based on ROC-AUC)

Generated probabilistic predictions (predict_proba()[:, 1]) on private_trip_data.csv (21,764 records).
Performed shape checks, NaN verification, and summary statistics (describe()) on predictions before saving out to submission.csv.


##📈 Key Policy Recommendations & Business Impact

Mandatory Regional Rail-First Ban: Implement a strict booking ban on short-haul flights where active direct high-speed rail exists and travel time is under 4 hours (e.g., Munich–Berlin, Frankfurt–Paris).
Virtual-by-Default for Internal Meetings: Target the Internal Meetings hotspot (9,114 trips) by requiring executive-level pre-approval prior to travel authorization.
Automated SLA Triggers (14-Day Advance Rule): Eliminate the 6.4-day approval delay by establishing automated procurement approval triggers at least 14 days before departure.
Proactive Carbon Risk Interception: Integrate the classifier into corporate booking portals to score active travel requests in real time and propose low-carbon alternatives before confirmation.
